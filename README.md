# AIO - All In One
Simple college project made with plain HTML, CSS and JavaScript (no backend, no libraries).

Open `index.html` in a browser. Pages: Home, Groceries, Medicines, Printouts, Home Services, Cart, Orders.

- `css/style.css` - all the styling
- `js/data.js` - products and services list
- `js/app.js` - cart, promo codes, print price calculator, service booking, orders (saved with localStorage)
